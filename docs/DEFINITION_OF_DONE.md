# Definition of Done

A task is done when:

- scope matches TASKS.md;
- public input validated;
- permissions checked;
- migration included if needed;
- tests exist and pass;
- mobile UI checked when relevant;
- errors are readable;
- logs expose no secrets/private location;
- docs/contracts updated;
- no unrelated refactor.

Compatibility also requires:

- deterministic rule;
- provenance;
- unknown-state handling;
- golden tests.

Safety also requires:

- expiry;
- revoke;
- privacy review;
- rate-limit behavior.
