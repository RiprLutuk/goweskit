# Ride Safety

1. Explicit user action starts tracking.
2. High-entropy expiring token.
3. Prefer token hash storage.
4. Rate-limit public share.
5. Show timestamp/accuracy.
6. Immediate revoke/end.
7. Define retention.
8. Never expose live location publicly.
9. Never claim emergency dispatch.
10. Test valid/expired/revoked/invalid/abused token.
