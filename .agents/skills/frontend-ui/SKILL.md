# Frontend UI

1. Read `DESIGN_SYSTEM.md`.
2. Mobile-first: 360/390/430 px.
3. Avoid generic SaaS dashboards.
4. Technical screens need simple + detailed explanations.
5. Unknown specs should be actionable, not errors.
6. Use `packages/ui` and `packages/contracts`.
7. Add loading, empty, error, and permission states.
8. Respect reduced motion.
